# مستشفى حضرموت الحديث | Hadramout Modern Hospital (HMH) - Frontend

بوابة المريض ولوحة التحكم الإلكترونية لمستشفى حضرموت الحديث، مبنية بأحدث تقنيات الويب مع مراعاة أعلى معايير تجربة المستخدم وأسلوب التصميم المسطح الحديث (**Minimalism Flat Modern Style**).

---

## 🚀 التقنيات المستخدمة (Tech Stack)

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Alexandria Arabic Google Font (`var(--font-alexandria)`)
- **Design System**: Minimalism Flat Modern Style (أسطح مسطحة بيضاء، ألوان طبية متناسقة، مسافات بيضاء واسعة، بدون ظلال ثقيلة).

---

## 🗺️ خريطة الصفحات والوحدات (Pages & Modules)

### الصفحات الأساسية الحالية (Core App Pages)

| المسار (Route) | الاسم | الوصف |
| :--- | :--- | :--- |
| `/` | الصفحة التعريفية (Landing Page) | واجهة المستشفى الترحيبية، الأقسام، الميزات، والأسئلة الشائعة. |
| `/app` | لوحة التحكم (Dashboard) | البوابة الرئيسية للمريض بنظام Bento Grid والودجات السريعة. |

### 💡 أفكار الوحدات والصفحات المقترحة (Proposed Module Ideas)

1. **الوصفات الدوائية والصيدلية الذكية (`/app/prescriptions`)**:
   - عرض الأدوية المصروفة للمريض، جدول الجرعات، التنبيهات، وإمكانية إعادة طلب الدواء للتوصيل من صيدلية المستشفى.
2. **الاستشارات الطبية عن بعد (`/app/telehealth`)**:
   - حجز واستشارة الأطباء عن بعد عبر مكالمات الفيديو والمحادثات المباشرة دون الحاجة للحضور للمستشفى.
3. **باقات الفحص الشامل والعروض (`/app/packages`)**:
   - استعراض باقات الفحص الدوري (باقة القلب، فحص السكري، صحة المرأة، الفحص الشامل) مع الحجز الفوري.
4. **خدمات الطوارئ والإسعاف السريع (`/app/emergency`)**:
   - طلب إسعاف فوري مع تحديد الموقع المباشر (GPS)، أرقام الطوارئ السريعة، وإرشادات الإسعافات الأولية.
5. **إدارة ملفات العائلة (`/app/family`)**:
   - ربط ومتابعة الملفات الصحية للأبناء والوالدين من حساب واحد وإدارة مواعيدهم.
6. **الفواتير والتأمين الصحي (`/app/insurance` أو `/app/billing`)**:
   - الاطلاع على الفواتير الطبية، نسبة تغطية شركات التأمين، والموافقات الطبية مع خيارات السداد الإلكتروني.
7. **جدول تطعيمات الأطفال (`/app/vaccinations`)**:
   - جدول زمني تفاعلي لتطعيمات الأطفال المعتمدة مع تنبيهات تلقائية قبل كل جرعة.
8. **الرعاية والتمريض المنزلي (`/app/home-care`)**:
   - طلب زيارة ممرض أو طبيب إلى المنزل لتغيير الضمادات، تركيب المحاليل، وسحب عينات التحاليل.
9. **بنك الدم والمبادرات الصحية (`/app/blood-bank`)**:
   - متابعة حالات الاحتياج العاجل لفصائل الدم، تسجيل رغبة التبرع، وسجل تبرعات المريض السابقة.
10. **صوت المريض والتقييمات (`/app/support` أو `/app/feedback`)**:
    - تقديم الملاحظات والشكاوى المباشرة لإدارة المستشفى وتقييم مستوى الخدمات مع تتبع الحالة.
